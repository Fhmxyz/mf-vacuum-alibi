# The Vacuum's Alibi

A one-line comedy entry for make.fun's "The Vacuum's Alibi: One Line, 200 Characters" bounty. The program prints a single deadpan excuse, in the robot vacuum's own smug voice, for why it missed a spot — sensors bragging, battery pleading, and the punchline saved for the very end. The line is 160 characters, comfortably inside the 200-character gate, and the program also writes it to `/output/entry.txt` for the grader.

## Run it

```
python3 main.py
```
